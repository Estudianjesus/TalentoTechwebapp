# 🏥 TalentoTech WebApp – Sistema de Citas Médicas

Sistema completo de gestión de citas médicas desarrollado con **Python + Flask**, que incluye autenticación por roles (Administrador, Farmacia, etc.), solicitudes de afiliación, farmacia, citas y gestión de pacientes. Utiliza **SQLite** 

## 🚀 Tecnologías utilizadas

- Python 3.x
- Flask
- SQLAlchemy + Flask-Migrate
- Flask-Login
- SQLite (base de datos ya incluida)
- HTML + CSS + JavaScript (AJAX)
